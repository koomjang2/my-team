# My Team — 애터미 실질 직급 계보도

보름(상반기 1~15일 / 하반기 16일~말일) 단위로 직급을 맞추기 위해,
내 계보도에서 **누구를 SSM으로 보내고, 누구를 SM에 보내면서 DM을 맞출지**를 짜보는 도구.

## 실행

```bash
npm install
```

```bash
npm run dev
```

## 엔진 검증

```bash
npm test
```

직급 달성 규칙(롤업 · 레그 카운팅)이 애터미 문서상 필요 인원과 일치하는지 확인한다.
STM 52명 / RM 160명 / CM 484명 / IM 1,456명.

## 사용법

1. **맨 위 바** — 달성하고자 하는 직급, 내 이름, ID, 메모, 대상 반기를 정한다.
2. **왼쪽 (계보도 구성)** — `좌`/`우` 버튼으로 하위를 붙여 계보도를 짠다.
   - 카드의 **메모 이외 영역**을 터치하면 달성할 직급을 고르는 팝오버가 열린다.
     직급 8종 + 소비자(CSM) 중에서 선택하고, 이름·ID·분류(실질/예비)·PV 목표를 함께 입력한다.
   - 카드의 **메모** 버튼을 터치하면 아래에서 메모 스낵바가 올라온다 (수정 / 닫기).
3. **오른쪽 (실질 직급 계보도)** — 왼쪽에서 직급을 고칠 때마다 즉시 다시 계산된다.
   각 사람이 계획한 직급에 실제로 도달하는지, 못 간다면 무엇이 몇 명/몇 만 PV 부족한지 보여준다.

빈 바탕을 드래그하면 화면 이동, `Ctrl`+휠 또는 두 손가락 핀치로 확대·축소된다.

## 직급 달성 조건

| 직급 | 조건 |
|------|------|
| SSM | 보름 소실적 좌/우 각 150만 PV (몸PV 합산 가능) |
| SM | 보름 소실적 좌/우 각 250만 PV (몸PV 합산 가능) |
| DM | 좌에 SM 2명 이상 **AND** 우에 SM 2명 이상 |
| SRM | 좌에 DM 2명 이상 AND 우에 DM 2명 이상 |
| STM | 좌에 SRM 2명 이상 AND 우에 SRM 2명 이상 |
| RM | 좌에 STM 2명 이상 AND 우에 STM 2명 이상 |
| CM | 좌에 RM 2명 이상 AND 우에 RM 2명 이상 |
| IM | 좌에 CM 2명 이상 AND 우에 CM 2명 이상 |

- 몸PV는 항상 좌/우 중 **더 적은 쪽(소실적)** 에 합산된다.
- **DM 이상은 몸PV로 직급을 달성할 수 없다.**
- 상위 직급자는 하위 직급 자격도 만족한다(롤업). 같은 라인 안에 중첩해서 세도 된다.
- 소비자(CSM)는 어떤 직급 자격에도 포함되지 않는다.
